# Tiger Hiking

這是一個提供登山活動資訊和報名功能的網站。

---

## ✨ 功能列表 (Features)

### 一般功能
* **活動瀏覽**: 查看所有登山活動的列表及詳細資訊。
* **首頁**: 顯示最近的活動。
* **活動報名**: 使用者可以填寫表單報名參加活動。
* **聯絡我們**: 提供聯絡表單讓使用者可以提交問題。
* **最新消息**: 查看網站的最新公告。
* **常見問題**: 提供常見問題的解答。
* **關於我們**: 顯示網站的背景及宗旨。
* **活動相簿**: 瀏覽過去活動的照片。

### 會員中心功能 (未來開發項目)
* **會員基本資料管理**:
  - 檢視與編輯個人資料。
  - 更改密碼。
  - 上傳或更換頭像。
* **我的活動管理**:
  - 檢視已報名的活動清單。
  - 查看活動詳細資訊。
  - 編輯報名資訊。
  - 取消報名。
  - 查看活動歷史紀錄。
* **通知與公告**:
  - 檢視與會員相關的通知（如報名成功、付款成功等）。
  - 查看最新公告。
* **付款與訂單管理**:
  - 檢視付款紀錄與訂單詳情。
  - 提供退款申請功能。
* **收藏與偏好設定**:
  - 收藏感興趣的活動。
  - 設定通知與活動類型偏好。
* **客服與支援**:
  - 聯絡客服。
  - 查看常見問題。
  - 問題回報功能。
* **會員等級與成就**:
  - 顯示會員等級與升級條件。
  - 成就系統（如參加活動數量、累積里程等）。
* **安全與隱私**:
  - 查看登入紀錄與管理裝置。
  - 設定隱私偏好。

## 🚀 技術棧 (Tech Stack)

* **前端框架**: React
* **語言**: TypeScript
* **建置工具**: Vite
* **資料請求**: Apollo Client (GraphQL)
* **路由**: React Router
* **樣式**: Tailwind CSS
* **程式碼檢查**: ESLint
* **UI 元件**: Lucide React (圖示), React Toastify (通知)

## 📦 如何安裝和執行 (Installation and Setup)

1. **複製專案**:
    ```bash
    git clone <repository-url>
    cd tiger-hiking
    ```

2. **安裝依賴**:
    ```bash
    npm install
    ```

3. **啟動開發伺服器**:
    ```bash
    npm run dev
    ```
    應用程式將會執行在 `http://localhost:5173`。
